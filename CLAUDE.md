# Правила для ассистента

1) Деньги только в копейках, тип int. Никаких float и Decimal.
2) Бизнес-правила (тарифы, промокоды, переходы статусов) лежат в app/constants.py, из env берутся только настройки окружения.
3) Слои: роутер → сервис → репозиторий. commit делает только сервис.
4) Сервис возвращает Pydantic-схемы, ORM-объекты наружу не выходят.
5) Схема базы меняется только через миграции Alembic.
6) После изменений запускать uv run pytest.
